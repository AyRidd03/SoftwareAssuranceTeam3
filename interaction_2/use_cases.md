The Head Admin would like to create and assign another Admin to a group of users to manage a specific branch of the company.
Using Keycloak, the Head admin can create a subrealm from the master realm and assign another admin to the subrealm
which manages the applications and users assigned to that subrealm. 

An external Admin wishes to manage their users while on vacation. The Admin logs in using a VPN and receives an error. 
The Head Admin has set the Realm setting to External Request, which requires the External Admin to use their private IPv4 address.
