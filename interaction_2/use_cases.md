The Head Admin would like to create and assign another Admin to a group of users to manage a specific branch of the company.
Using Keycloak, the Head admin can create a subrealm from the master realm and assign the group the another admin is in to the subrealm
which manages the applications and users assigned to that subrealm. 

A user is trying to access a client's website and the client would like to authenticate the user. Using a Keycloak Client Adapter, 
Keycloak requests the user with consent to provide credentials. After the user has provided credentials, Keycloak validates their authentication, group assignment, and role access. 
Keycloak then returns to the client the authentication and role of the user.

An external Admin wishes to manage their users while on vacation. The Admin logs in using a VPN and receives an error. 
The Head Admin has set the Realm setting to External Request, which requires the External Admin to use their private IPv4 address.
